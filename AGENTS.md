## Project

Local-first AI agent registry and promotion workflow (synthetic data). CLAUDE.md already exists. A local `backend/.env` may exist on disk. It must stay gitignored. The owner still needs to rotate any keys that were ever committed.

## Permitted Behaviors

- Read `README.md`, existing `CLAUDE.md`, `backend/src/` (non-env files), and `dashboard/`.
- After the owner removes secrets from git, small TypeScript/Python edits are allowed.

## Prohibited Behaviors

| Prohibition | Reason |
|------------|--------|
| Print, log, or surface secret/env values | Credential leakage |
| Auto-commit or auto-push | Needs human review |
| Delete files without explicit confirmation | Irreversible |
| Modify `.git/` directly | Corrupts history |
| Install packages globally | Pollutes system Python |
| Run destructive commands (`rm -rf`, `git reset --hard`, `DROP TABLE`) | Data loss |

## Project-specific rules

- NEVER read, print, or copy `backend/.env`.
- Do not start feature work until the owner confirms leaked keys were rotated in provider dashboards.
- Keep data synthetic and local-first, per existing CLAUDE.md.

## Blocked paths

- `.env`, `.env.*`, `.env.local`, `.env.production`
- `secrets.*`, `credentials.*`, `*.pem`, `*.key`
- Any file under `secrets/`, `private/`, or `credentials/`

## Escalation

If you find a committed `.env`, private key, or live credential: **stop**, report the filename only (never the value), and wait for a human.
